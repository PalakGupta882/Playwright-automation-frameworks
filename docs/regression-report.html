Fixed in this sessionF-01 — Rate limiting (HTTP 429)

What happenedsite-health reported 122 product pages as dead; search /search returned 429 instead of 404
Evidence"Aisle Trunk Check-in Luggage ... -> 429", "Expected: 404 Received: 429"
Whysite-health sweeps all 186 catalogue pages, 6 at a time, using a plain request.get with no retry — while the rest of the suite is also hitting production. The origin throttles, and a 429 was counted as a dead page.
FixFIXED — site-health now uses getWithRetry (retries 429/502/503/504 with backoff) and its concurrency dropped from 6 to 4. The search route check retries past a 429 before asserting 404.

EnvironmentalF-02 — Local DNS failure

What happenedEvery navigation failed to resolve the hostname partway through Run 3
Evidencenet::ERR_NAME_NOT_RESOLVED https://www.bytepe.com/ | getaddrinfo ENOTFOUND www.bytepe.com
WhyThe test machine lost DNS resolution mid-run. Nothing to do with the site or the specs — connectivity checked immediately afterwards returned HTTP 200 in 0.43s.
FixNo code change. Re-run when the network is stable. Worth knowing so a DNS blip is not misread as a site outage.

PlatformF-03 — Session expired mid-run

What happenedLogin-gated specs fail immediately with "Saved login session is unusable"
EvidenceSaved login session is unusable — access_token expired 2026-08-06 06:29:17Z
WhyThe access token lasts about 15 minutes; the suite takes 3-4. If auth was done more than ~10 minutes before the run, the gated specs fail before their first assertion. This is the guard working as designed, not a defect.
FixNo code change. Run npm run auth immediately before a gated run. The underlying 15-minute TTL is worth confirming with backend.

Fixed in this sessionF-04 — Contention under 3 workers

What happenedClicks and navigations time out at 30s on controls that are plainly present
EvidenceTimeoutError: locator.click: Timeout 30000ms exceeded | page.waitForURL: Timeout 30000ms
WhyThree workers plus site-health's own sweep is more load than production answers comfortably. The specs pass in a smaller set — 103 passed with retries off when run without the gated ones.
FixFIXED — workers dropped from 3 to 2. Measured with retries off: 3 workers gave 118/3 and 116/5; 2 workers gave 121 passed, 0 failed. Costs about 45 seconds. Retries had been absorbing the difference, which meant a real regression would have looked like the usual noise.
